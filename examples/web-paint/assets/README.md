# External paint UI assets

- `meadow.png`: generated for this demo with OpenAI ImageGen, September 24, 2026. Crayon landscape with blue sky, a cloud, sun, green hills and daisies. Loaded only through **ファイル → サンプルを開く**, as a new editable image layer.
- `icons/pencil.svg`, `icons/brush.svg`: Microsoft [Fluent Emoji](https://github.com/microsoft/fluentui-emoji), flat Pencil and Paintbrush assets. MIT license in `icons/LICENSE-emoji`.
- Other SVG icons: Microsoft [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons), distributed in `@fluentui/svg-icons` version 1.1.341. MIT license in `icons/LICENSE`.

Assets are local; using the page does not require an external CDN.
